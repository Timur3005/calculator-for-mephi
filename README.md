# calculator-for-mephi

Консольный калькулятор на Java (учебное задание МИФИ).

## Запуск

```bash
./gradlew build
java -cp build/classes/java/main calculator.Main
```

## Использование

Вводится первое число, затем операция (`+`, `-`, `*`, `/`) и второе число. Результат становится первым операндом следующей операции.

- `C` — сбросить результат и начать заново
- `S` — выйти

Команды регистронезависимы. Деление на ноль и неподдерживаемая операция выводят сообщение об ошибке и не меняют результат.

## CI

GitHub Actions собирает проект и запускает тесты на каждый PR. Ветка `main` защищена: влить PR можно только при зелёной сборке.
